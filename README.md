# 문자 사냥 / TEXT HUNTER

문자 하나로 시작해 적의 뒤를 잡고, 흡수한 문자와 같은 문자 벽을 지워 미로를 개척하는 실시간 잠입 게임.

## 현재 버전
- v0.40 — 순환형 확장 미로와 모바일 드래그 조작
- 실행: [index.html](./index.html)을 Chrome/Edge로 열기. 별도 설치, 서버, CDN이 필요하지 않습니다.
- PC: 방향키/WASD 이동 · Space 길 막기 · Tab 전체 지도 · P 일시정지 · R 재시작
- 모바일: 게임판 또는 아래 영역에 손을 대고 원하는 방향으로 밀어 유지하면 연속 이동. 손을 떼거나 중심으로 돌아오면 정지합니다. 길 막기는 @ 흡수 후 표시됩니다.
- 목표: @ → & → %를 흡수하고 문자 벽을 직접 개척해 북쪽 외곽 출구에 도달합니다. 전 적 처치는 필수가 아닙니다.

## 핵심 규칙
1. 입이 벌어진 쪽이 캐릭터 정면입니다. 적의 등 뒤에서 접근해야 흡수할 수 있습니다. 정면/측면 접촉은 패배입니다.
2. `@` 적을 먹으면 `@` 벽을, `&` 적을 먹으면 `&` 벽을 지울 수 있습니다. `%`는 바깥쪽 지름길을 여는 데 이용됩니다.
3. `#` 벽은 영구적으로 남습니다. 플레이어가 개척한 길은 적도 지나갈 수 있습니다.
4. 적을 먹으면 먹물 +1(최대 3개). Space로 약 8초간 유지되는 임시 `+` 벽을 전방에 만들 수 있습니다.
5. 짧은 시간에 연속 사냥하면 일시적 이동속도와 먹물 보너스를 얻습니다.
6. `!`는 적의 추적/공격 경고, `?`는 수색 신호입니다.
7. 머리 위 화살표는 **다음 회전**이며, 예고 중에는 기존 방향의 후방 판정이 유지됩니다.
8. 일시정지·도움말·백그라운드 전환은 게임 시간을 멈춥니다. 임시 벽과 콤보도 보존됩니다.
9. 플레이어는 검은 입 모양을 유지합니다. 흡수한 문자는 하단의 벽 통과 안내로 확인합니다.

## 개발 원칙
- 초기 화면은 흑백이며, 흡수한 결과로만 색을 서서히 드러낸다.
- 시작 중앙 미로를 보존하고 주변을 짧게 확장하여 이전 통로를 계속 활용한다.
- 공격은 자동이고, 이동·우회·방향 판별이 핵심 전술이다.
- 적 AI는 항상 플레이어 좌표를 아는 대신 마지막 관찰 지점과 이동 흔적을 추적한다.
- 기능을 늘리는 것보다 **읽히는 방향, 공정한 AI, 재미있는 뒤잡기**를 우선한다.

## v0.31 개선
- 회전 방향을 한 박자 먼저 예고하고 다음 박자에 회전합니다. 회전 직후 같은 박자에 이동하지 않습니다.
- 시야 밖 적도 순찰합니다. 이동 흔적은 실제 통로로 도달 가능한 경우에만 조사하며, 매복 예측은 중간 벽을 뛰어넘지 않습니다.
- 흡수 애니메이션 중 도움말/일시정지 후에도 흡수가 이어집니다. 사망 화면에 실제 원인을 표시합니다.
- 흡수마다 최고 기록 저장, 잘못된 저장 데이터 복구, 실제 속도와 표시 통일(최대 140%, 콤보 중 155%).
- `%`의 외곽 지름길 안내·벽 강조, 모바일 방향키 최소 44px·하단 고정·다중 터치 소유권 및 취소 처리.

## 브라우저 회귀 테스트
Python 3으로 저장소 루트에서 서버를 실행한 뒤, Playwright와 Chromium이 설치된 환경에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
# 다른 터미널, 동일한 저장소 루트
node tests/browser-smoke.cjs
```

기본 Chromium 경로는 `/usr/bin/chromium`입니다. 필요하면 `CHROMIUM_PATH`와 `TEXT_HUNTER_URL`을 지정합니다. 테스트 도구는 개발 검증용이며 게임 실행에는 필요하지 않습니다.

## v0.32 화면 정리
- 후방 초록 네모와 플레이어 내부 색점·문양·광륜·잔상 제거. 검은 입의 열린 쪽만으로 내 방향을 읽습니다.
- 외형 비교·지도·소리·새 게임·도움말 메뉴와 사이드바 제거. 플레이 화면에는 흡수 수·일시정지·다음 행동 안내만 표시합니다.
- 길 막기는 첫 @ 흡수 후 표시하며 남은 사용 횟수를 함께 적습니다. 모바일은 방향키와 길 막기만 사용합니다.
- 지도(Tab)·재시작(R)은 기존 키보드 단축키로 유지하고, 사망/완료 화면의 주 버튼으로 다시 시작할 수 있습니다.
- 성장 피드백은 통과 가능한 문자 벽과 실제 길 확장에 집중합니다. 아래 v0.31 내용의 후방 네모·색 장식 설명은 과거 동작입니다.

## v0.40 개발 결과
- 중앙 43칸 보존. 단계별 잠재 이동 면적은 43 → 336 → 607 → 1,162칸이며 적은 16명입니다. 문을 모두 자동 개방하지 않고 보유한 문자에 맞는 벽을 직접 지웁니다.
- 북쪽 두 출구로 A↔B, 북쪽·동쪽 연결로 A→B→C→A를 구성합니다. &는 남쪽·서쪽, %는 여러 지역과 다시 만나는 큰 외곽 통로를 엽니다.
- 플레이어 추적 카메라와 고정 문자 크기, 현재 시야와 흐린 지형 기억을 분리했습니다. 적은 현재 보이는 영역에만 그립니다.
- 방향 버튼을 제거하고 Pointer Events 기반 드래그를 구현했습니다. 작은 흔들림 무시, 대각선 방향 안정화, 취소·다중 터치·회전 시 입력 정리를 포함합니다.
- 소리는 열린 통로를 따라 최대 7칸 전파됩니다. 숨은 플레이어의 현재 위치를 알리지 않고 사건 지점을 조사합니다. 막힌 사건 타일은 소리가 도달한 쪽의 인접 통로를 조사합니다.
- 추가 검증: `node tests/expansion-drag.cjs`. 기존 테스트와 합계 20개 브라우저 검사입니다. 순환 역습은 상태를 통제한 시나리오이며 자연스러운 완주 난이도를 검증한 결과는 아닙니다.
- 설계 원안은 [MAP_EXPANSION_PLAN.md](./MAP_EXPANSION_PLAN.md). 목표 면적·적 수 등은 원안과 이번 구현 실측을 구분합니다.
